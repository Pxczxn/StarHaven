# 星栖商家管理端

Vue 3 + TypeScript + Vite + Vue Router + Naive UI + Pinia + Axios + ECharts

```bash
pnpm install
pnpm dev
```

开发地址：http://127.0.0.1:5569  
接口代理到后端 `5568`。

| 账号 | 密码 | 角色 |
|------|------|------|
| host | 123456 | 商家 |
| admin | 123456 | 平台管理员 |

## 页面

- 登录页：左右分栏、验证码、记住密码
- 首页：统计卡片、订单/收入趋势图、热门房源排行
- 用户 / 房源 / 订单 / 订单详情：对接 `/admin` 接口
- 房东 / 评论 / 消息 / 财务 / 优惠券 / 系统设置：按原型实现，演示数据展示
