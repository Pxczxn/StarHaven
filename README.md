# 星栖民宿管理系统

> 星辰为引，栖心而居

星栖是一家以"星空、归宿、旅行"为主题的精品民宿品牌管理系统，包含后台管理端、租客端 Web/H5 和后端服务。

## 项目结构

```
星栖/
├── backend/                    # 后端服务 (Spring Boot)
├── web/                        # 后台管理端 (React + Vite)
├── h5/                         # 租客端 H5 (React + Vite)
├── data/                       # SQLite 运行数据目录
├── 基础文档.md                  # 项目需求文档
├── 开发文档.md                  # 技术开发文档
├── 模块开发文档.md              # 模块任务文档
└── README.md                   # 本文件
```

## 快速开始

### 环境要求

- JDK 21+
- Maven 3.9+
- Node.js 24+
- npm 11+

### 启动后端

```bash
cd backend
mvn spring-boot:run
```

后端服务运行在 `http://localhost:8888`

SQLite 数据库文件位于项目根目录 `data/xingqi.db`。仓库保留了 `data` 目录占位文件，首次启动时 SQLite 会自动创建数据库文件。

### 启动后台管理端

```bash
cd web
npm install
npm run dev
```

后台管理端运行在 `http://localhost:5173`

### 启动租客端 H5

```bash
cd h5
npm install
npm run dev
```

租客端运行在 `http://localhost:5174`
